# Go Backend Template

A Go backend template that uses Air for hot reloading, Fiber for web framework, and Ent for database ORM.

## Project Structure

```
go-backend-template/
├── .env
├── .env.example
├── .gitignore
├── docker-compose.yml
├── go.mod
├── go.sum
├── main.go
├── README.md
├── ent/
├── internal/
│   ├── api/
│   │   └── routes.go
│   ├── config/
│   │   ├── app.go
│   │   └── config.go
│   └── logger.go
└── tmp/
    └── main
```
